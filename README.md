#Study Time Tracker 

#This program asks the user how many hours they studied today and then calculates how many hours they are on track to study for the entire week. It helps users quickly estimate their study habits and stay aware of whether they are meeting their weekly goals. The program also checks for invalid input to make sure the user enters a valid number. 

#To run it open your terminal and run python app.py
